# JOWHAR — جوهر للعطور

Python 3.10+ فقط، بدون تثبيت مكتبات. قاعدة البيانات SQLite، والصور في data/uploads.

## التشغيل محلياً
    ADMIN_USER="اسم المستخدم" ADMIN_PASSWORD="كلمة المرور" python3 server.py
الموقع: http://localhost:8000 — اللوحة: http://localhost:8000/admin
يُنشأ حساب المدير عند أول تشغيل فقط من متغيرات البيئة (كلمة المرور تُخزَّن مُجزّأة بـ scrypt). بعدها غيّر البيانات من تبويب «الحساب».

## النشر
Render أو Railway: ارفع المشروع إلى GitHub، أنشئ Web Service بأمر `python3 server.py`، وأضف ADMIN_USER و ADMIN_PASSWORD في Environment.
تنبيه: الاستضافة المجانية غالباً تمسح القرص عند إعادة التشغيل؛ لحفظ البيانات والصور استخدم قرصاً دائماً (DATA_DIR) أو VPS صغيراً.
النطاق: أضف نطاقك من إعدادات الاستضافة ثم اضبط سجلات DNS التي تعرضها.
